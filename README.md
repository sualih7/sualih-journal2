# Sualih Journal

Beautiful MT5 trade tracker for Gold/XAUUSD.

## Live Demo
Once deployed to GitHub Pages, visit:  
`https://your-username.github.io/sualih-journal/`

## Features
- 📁 Drag-drop MT5 CSV import
- 📊 Interactive equity curve
- 📋 Full trade table with Win Rate & Profit Factor
- 💾 LocalStorage (no backend needed)

## Deployment Steps
1. Go to https://github.com/new
2. Name repo: `sualih-journal`
3. Check "Initialize this repository with a README"
4. Create repository
5. Click "Add file → Upload files"
6. Upload `index.html` (from localhost)
7. Settings → Pages → Source: `main` / `/root`
8. Done! URL: `https://your-username.github.io/sualih-journal/`
